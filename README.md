# Nova Ride

Moderni, responsiivinen autokaupan demo GitHub Pagesille.

## Ominaisuudet
- Autokatalogi, hakukenttä, kategoriasuodattimet ja hinnan mukaan lajittelu
- Auton tietonäkymä modal-ikkunassa
- Koeajon varausdemo ja paikallinen ostoskorilaskuri
- Responsiivinen ulkoasu mobiilille ja työpöydälle
- GitHub Pages -yhteensopiva staattinen toteutus

## Demo
`https://porinbear.github.io/carshop/`

Demo käyttää Unsplash-kuvia. Yhteydenottolomake on frontend-demo: se näyttää onnistumisviestin, mutta ei vielä lähetä tietoja palvelimelle.
